# Nyaitter Scratch Paint fork

This fork adds Nditor collaboration metadata, preserves local paint gestures
during remote updates, and keeps costume and remote selection updates connected
to the collaborative Paper.js fork.

Upstream: https://github.com/TurboWarp/scratch-paint
Nyaitter fork: https://github.com/Nyaitter/scratch-paint

The original source, licenses and upstream build scripts are preserved.
